# Liminal Space

This repository contains small prototype projects.

## Mushroom Island

`mushroom_island.py` implements a terminal game inspired by **Dig Dug 2**. You roam an island made entirely of mushrooms while hungry aliens try to eat through it. Dig away mushrooms to cut off chunks of the island and drop aliens into the void.

### Running the Game

```
python3 mushroom_island.py
```

* Use the arrow keys to move.
* Press `space` or `d` to dig the mushroom under you.
* Trap all aliens by cutting off pieces of the island. Avoid letting an alien touch you.
* Press `q` to quit.
